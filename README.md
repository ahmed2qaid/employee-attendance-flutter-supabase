# Employee Attendance Calculator — Flutter Web + Supabase

نسخة Flutter Web متصلة بـ Supabase مع نظام ورديات مرن.

## التهيئة
1. أنشئ مشروع Supabase.
2. شغّل `supabase/schema.sql`. يمكن إعادة تشغيله لترقية قاعدة قديمة وإضافة حقول التناوب.
3. نفّذ `flutter pub get`.
4. شغّل التطبيق عبر `--dart-define=SUPABASE_URL=... --dart-define=SUPABASE_ANON_KEY=...`.

## نظام الورديات
- لكل موظف اختيار وردية واحدة أو ورديتين متناوبتين كل 7 أيام.
- الورديات الجاهزة: صباحي 06:00–14:00 ومسائي 14:00–22:00.
- في حالة الورديتين يُحدد تاريخ بداية دورة التناوب، ثم يبدّل النظام تلقائيًا كل 7 أيام حتى عند الانتقال بين الشهور والسنوات.

## سياسة الدوام
- سماح التأخير والانصراف المبكر إعدادان عامان لجميع الموظفين.
- لا يوجد سماح خاص لكل موظف.
- تجاوز السماح يجعل النظام يحتسب كامل مدة التأخير/الانصراف المبكر.
- الجمعة مستثناة تلقائيًا.
- لا بصمات = غياب، بصمة واحدة = معلق، بصمتان = حضور.
- 8 ساعات = 480 دقيقة = يوم عمل واحد.

## Supabase
- `app_settings`: السماحات العامة.
- `employee_policies`: نظام الورديات وتاريخ بداية التناوب لكل موظف.
- `attendances`: سجلات الحضور.

> RLS المرفق مفتوح للتجربة ويجب تقييده قبل الإنتاج.
